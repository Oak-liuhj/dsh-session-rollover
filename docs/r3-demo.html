0. 基线冻结声明（v1.0 · 2026-11-04）

本文件即设计基线 v1.0，自 2026-11-04 冻结。右侧栏 sidebar.right.pane.tab 形态是唯一主形态，屏 1 / 屏 2 的布局、文案、状态、交互默认即为开发实现口径；输入框上方旧 dock 只作为 R2-08 兼容开关存在，不再作为独立形态演进。

冲突时以本文件为准的方向只有一处：UI 形态与交互。需求 v1.2 与 PRD v1.1 应回写条款与判据来对齐本文件，不能反过来要求原型改回底部抽屉。数值型判据（字数、卷数、命中区、对比度）以本文件与 设计基线_R2R3_v1.0.md 为准。

v0.1 → v1.0 只动了三类：① 基线标识与冻结声明（本段）；② WCAG 2.2 AA 可达性修订——状态标签改为随文案流内联、三处图标按钮命中区补到 24×24、状态/次要文字改用文本安全色（--*-txt，详见 §5）；③ 无结构改动，屏数、组件、五态、九条决议落地位置均未变。冲突清单全文见同目录 设计基线_R2R3_v1.0.md，含每条的设计建议与验收判据；下表为摘要。
